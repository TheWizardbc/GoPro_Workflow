GoPro Workflow Privacy Policy

Last updated: 23 November 2026

GoPro Workflow is a Windows desktop application for processing GoPro video and GPS data and optionally publishing validated Street View sequences.

Google authorization

When a user selects “Sign in with Google,” GoPro Workflow requests access to the Google Street View Publish API using the following OAuth scope:

https://www.googleapis.com/auth/streetviewpublish

This permission is used only to:

  • publish Street View sequences selected or prepared by the user;
  • retrieve upload, processing and publication status;
  • link local upload records to the corresponding Google Street View sequence.

Locally stored data

GoPro Workflow stores an OAuth authorization token locally on the user's computer so that authorization can be restored without a new sign-in at every startup. The application also stores local upload records and Google operation or PhotoSequence identifiers needed to retrieve status.

GoPro Workflow does not receive or store the user's Google password.

Data sharing

Google account data and OAuth credentials are not sold or shared with third parties. Video, imagery and GPS information are sent to Google only when the user explicitly requests a Street View upload.

Removing access

Users can sign out in GoPro Workflow or revoke access through the security settings of their Google Account. Local authorization credentials can also be removed from the application credentials folder.

Contact

For questions about authorization or data use, contact michel@faken.eu.
